# 开始 AimCodes 任务

先进入只读模式，不要修改任何文件。

1. 阅读 `AGENTS.md`、`README.md` 以及 `docs/` 中全部 Markdown 文件。
2. 运行：
   - `git status -sb`
   - `git diff --stat`
   - `git log --oneline -8`
3. 说明当前分支、已有未提交修改、最新提交和与 `docs/CURRENT_STATE.md` 的差异。
4. 用一句话复述任务目标，并列出准备修改与明确不修改的文件。
5. 判断需要运行哪些验证、是否涉及四语种、GA4、SEO、渲染器或生产站。
6. 在获得用户确认前，不提交、不推送、不合并、不部署、不修改外部平台。
