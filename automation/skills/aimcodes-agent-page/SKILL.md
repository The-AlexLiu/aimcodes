# AimCodes 英雄与主题准星页面

交付能看技能、看角色、预览／复制／调整主题准星的真实页面。最新已验收英雄页是界面与交互真源；角色内容与准星造型需要单独研究。

## 开始与短规划

1. 按 `aimcodes-maintainer` 和仓库 `AGENTS.md` 读取当前状态、运行 `pnpm task:context`、检查分支／已有修改。保护其他任务内容，只在本任务分支和工作目录修改。
2. 读取当前 `docs/SEO_OPERATING_POLICY.md`。检查用户指定的最新模板源码和正式构建桌面／手机表现；若用户没指定，先查已验收英雄页及近期修复，不能凭旧记忆选模板。已批准的不死鸟修订可作质量参照，路径见 [integration-map.md](references/integration-map.md)。
3. 优先查本站 GSC／GA4；结合当前搜索结果、联想与官方资料。区分账户数据、第三方估算和搜索观察；说明时间窗／缺口，不编造量，不把结果条数算需求。查站内已有承接页。
4. 开发前简短给出：一个核心意图、查询—意图—模块映射、Title／H1／描述、独立教程候选、模板功能差异，以及语言与索引提案。随后完成本地样稿；只询问会改变方向的缺失信息／规则冲突。

## 必须保留的体验

- 复用站点 Logo、导航、语言选择、面包屑、内容宽度、首图字号与位置、模块顺序、卡片／视频／图集布局、响应式和可访问交互。先对照已有功能，不另写外观相似但缺功能的壳。
- 保持技能、展开演示、角色介绍与动画、图集灯箱、简短角色资料、成品准星和相关内链。模块仅在有可靠素材和实际用途时加入；已有英雄不套用新英雄上线／解锁文案。
- 每个技能：官方本地化名称、右上官方图标、一句作用、简短操作与必要限制、匹配且可播放的实机视频。键位按模板；不使用字母代替图标，不加别名副标题／价格／重复问题标题／制作备注。
- 中文不默认并列英文名；五语同步，遵循各语种官方名称与玩家表达。FAQ 只补有搜索证据且正文未回答的内容。
- 准星区直接给成品、地图背景切换、缩放、复制反馈、带完整配置的编辑器入口和同语种内链。不额外添加调参面板，不用占位预览。
- 玩家文案只说作用与操作。准星说明描述实际形状、颜色和使用取舍，不强调“AimCodes 原创”，不冒充官方／选手配置。

## 媒体与准星质量门

制作或更换媒体／准星时读 [media-and-shape.md](references/media-and-shape.md)。

- 首图单独按桌面和手机裁切筛选：人物清楚、文字可读。
- 图集用动画或游戏里的角色近景／有辨识度的动作。不要用角色模型正背面、转台、设定 demo 图填图集；不要用纯手部、武器、远处小人或被遮挡的角色。每张都先视觉查看再采用。
- 图片铺满容器、裁切合适；保留点击放大、Esc／关闭／焦点返回；不叠加备注／来源。来源、时码、裁切和日期留在交付记录。
- 每个英雄的准星要在形状上容易区分。不能只换色，也不能只微调尺寸就称独有；把现有英雄准星在相同地图、相同缩放下并排看。差异不足时重做。
- 从同一份完整设置生成代码供 Canvas、复制和编辑器使用。解析成功只是必要条件，还要实测三者相同；不得替换现有英雄配置以制造差异。

## 语言、构建与发布

- 本地样稿默认五语均 noindex、排除 Sitemap；中文先验收，至少提供中英并按项目规则同步其余语言。
- 界面访问与搜索索引分别决策。发布前列各语言路径／目标查询、canonical、hreflang、robots、Sitemap。中文索引若受政策限制，说明冲突并等待该例外的明确授权；“发布页面”不自动意味着放开中文索引。
- 跑 `pnpm check:auto` 并审核报告；准星、语言、路由等按仓库要求验证，发布前跑完整 `pnpm check:release`。
- 可用辅助脚本检查数据与构建产物：
  ```bash
  node automation/skills/aimcodes-agent-page/scripts/check-agent.mjs --repo . --agent phoenix --index-locales en
  ```
  `--index-locales` 必填；本地样稿传 `none`。脚本只检查当前实现约定，不自动改文件；视觉差异、事实、视频内容和版权来源仍需人工式审核。
- 正式构建验收清单见 [verification-and-release.md](references/verification-and-release.md)。必须覆盖共享样式最后加载、实际悬停／焦点颜色和站内导航，不能只查 CSS 声明或开发环境。
- 未获授权只交付本地样稿。用户明确批准发布后，核对当前生产平台和提交；历史 Netlify／Cloudflare 说明不能代替实时证据。检查 PR 和真实部署预览，合并后核验正式域名。授权只适用于当前页面，不延伸到下一个英雄。

## 交付

简短说明完成状态、预览／正式链接、关键截图、媒体来源、修改／新增文件、跳过的既有修改、测试与限制。明确区分本地通过、已发布、线上实测和搜索增长。把具体版本／来源／索引决策留在仓库任务文档；不把一次发布授权写成 Skill 的长期许可。
