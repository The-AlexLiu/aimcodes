# 媒体与造型选择

## 可靠素材

优先官方英雄页的技能 Icon／演示，官方 VALORANT 动画和游戏画面。当前键位、技能机制与视频可能不在同一版本：官方页面与补丁交叉核验，避免把旧 HUD 当作当前操作。只在必要时说明版本限制，放交付记录，不卡片堆备注。

中文国服名称应从国服官方资料核验；国际服各语言从对应官方英雄页核验。第三方 API 只作交叉检查，不因字段可读就当官方真源。官网接口变化时先检查当前网页使用的公开资料入口，不猜 API 或英雄 ID。

原素材保留在 `data_raw`；中间帧在 `data_processed`，派生图片／视频进入 `public/images/agents/{agent}/`。记录原 URL、频道、时码、采集日期、尺寸、裁切和派生文件。原始图像不覆盖。可复现媒体处理脚本只改变派生文件。

每个图集候选先形成联系表或逐图查看，再在实际卡片内检查。优先三类互补镜头：脸部近景、清晰持枪或施法动作、有角色辨识度的战斗画面；数量按模板和素材质量，不用劣质镜头填满。

- 排除模型正背面对照、角色转台、概念设计 demo、微小人物、遮挡、纯枪／手部。
- 不拿 hero 静态肖像重复填图集。动画截图移除播放器 UI／字幕遮挡与黑边，保留实际画面，不伪造细节。
- `object-fit: cover` 只是起点；逐图设焦点。确认桌面、窄屏脸部和动作都没有被裁掉。
- alt 描述眼前画面，不堆英雄名／技能词。来源与说明放任务记录。

### 官方动画无法直接下载时

先诊断现有工具错误，不反复重试或引入非官方副本。已验证的替代方式：用 Ego Lite 正常打开官方公开视频，确认频道和视频标题，切到足够分辨率，暂停／定位时码，再截取纯画面区域；保留时码和截图范围。先看截图才能决定裁黑边的位置。不要复制不死鸟的固定时码／坐标到其他动画。直接打开 YouTube embed 可能因缺 Referer 返回 153；用正常观看页或站内合法嵌入核验，不把错误页截图当素材。播放器或登录授权需要用户处理时停止相关操作。

## 不同角色必须有不同造型

2026-10-19 已批准的对照：遐思为紧凑短线十字；贤者是带中心点、宽线形成的环状造型；不死鸟修订为中心留空、细长内十字＋独立短外线。这里记录区别，不是给后续角色指定固定造型。

设计前解析已存在的英雄代码。比较中心点、连通性、线条粗细／长度比例、内外层、中心间距和对称结构；颜色不参与几何判断。精确几何不同仍可能肉眼近似，所以不能用 JSON 不同作为最终通过标准。

用项目支持的真实参数构造造型，保持可瞄准与可见；不要为了像角色画复杂图案、使用 Canvas 假图或生成器无法恢复的参数。若设计使用编辑器尚不支持的字段，先让三方往返一致，或换成受支持的造型。

在同一地图同时查看 1× 与 5×，与已有角色并排比。独有形状、可见度、复制代码和编辑器带入都通过才交付。解析器通过不等于已在游戏客户端导入；未经实际导入不得声称实机验证。
