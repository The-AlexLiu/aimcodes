## 搜索意图门

- 详情目标查询：JSON 中对应 `valorant {agent} abilities`，其他语言使用现有该英雄本地化名称与技能说明。这里列的是目标词，不声称已有搜索量或排名。
- 详情最接近页面：英雄图鉴与同角色其他详情。每个详情解决独立角色的技能机制/官方演示、角色媒体和该英雄的专属可用准星，内容与操作按英雄不同，不能由另一英雄页面完成。
- 图鉴目标查询：VALORANT agents / 无畏契约英雄 / 对应本地化词。最接近准星库仅筛准星；图鉴解决找英雄、按职责筛选、角色预览及进入技能/准星详情，职责与单页不同。
- 独有价值：真实技能视频/图标、机制解释、角色素材、已解析的独立准星造型与地图/5×/复制/生成器；图鉴具备 30 人角色筛选和舞台切换。
- 索引语言：英语、西语、巴西葡语、简体中文、日语，本次按用户新要求开放此明确集合，整体语言分层不扩展到其他内容类型。
- 衡量：28 天核查 GSC/Bing 的发现、抓取、索引和页面/查询表现；不足则延至 56 天。实际收录、排名与流量是观察结果，不能由 Sitemap 提交保证。

## 提交通道

- Google：已有 Search Console 域资源权限，重新提交三个现有 Sitemap，核验提交结果；不使用不适用的一般网页 Indexing API。
- Bing：已有站点权限，重新提交三个 Sitemap，并核验 IndexNow 通知成功。
- IndexNow 修复：此前自动通知仅包含根目录和 sitemap.xml，没有具体新增页面。现在默认读取正式主 Sitemap，提取去重后的 canonical HTML 页面，拒绝外域/带认证/片段/XML 地址，每批最多 10000。正式版本匹配后才通知；CI 通过本地 Sitemap dry run 校验，dry run 不读所有权 key、不发送请求。
- IndexNow 只通知支持该协议的搜索引擎，不作为已向 Google 提交的证据；HTTP 200/202 只代表接受通知，不是收录证明。
