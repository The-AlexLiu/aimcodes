# AimCodes Catalog Scale Phase 3

日期：2026-08-17

## 目标与结果

本轮以扩大可持续 SEO 资产为目标，新增 100 个真实可用的原创准星详情。新增条目不是同一形状的换色复制，也不冒充职业选手配置。

| 指标 | 扩容前 | 扩容后 | 变化 |
|---|---:|---:|---:|
| 准星源数据 | 308 | 408 | +100 |
| 去重可见样式 | 300 | 400 | +100 |
| 可索引准星详情 | 156 | 256 | +100 |
| 四语种准星详情 URL | 624 | 1,024 | +400 |
| 本地化 HTML 路由 | 1,468 | 1,868 | +400 |
| 主 Sitemap URL | 848 | 1,248 | +400 |
| 图片 Sitemap 页面 | 724 | 1,124 | +400 |
| 图片 Sitemap 引用 | 1,348 | 2,148 | +800 |

## 数据设计

100 个新增样式继续使用现有 12 个经过验证的玩家意图家族：

- Micro Gap、Tap Dot、Compact Cross、Open Cross：各新增 9 个；
- Tracker、Twin Line、Pinpoint、Outer Mark、Tall Axis、Wide Axis、Burst Ring、Guard Frame：各新增 8 个。

生成器分两阶段运行：先复现原有 240 个原创条目，再从剩余候选中追加新形态。这个边界保证未来继续扩容时，旧 URL 对应的代码、颜色、名称和图片不会因目录总量变化而漂移。

## 每个页面具备的 SEO 资产

- 独立、可解析的 VALORANT 准星代码；
- 与现有普通目录不同的可见几何形态；
- 英语、西班牙语、巴西葡萄牙语和简体中文名称与描述；
- 从真实代码解析出的内线、外线、中心点和描边参数摘要；
- 对应家族的适用场景和使用取舍；
- 至少一个 Collection 上下文入口及详情页反向链接；
- 1080 × 1080 独立 WebP 预览图；
- 1200 × 630 独立 JPG 分享图；
- Self-canonical、hreflang、Open Graph、ImageObject 与 Sitemap 收录。

## 索引策略

本轮 100 个新增详情全部满足数据、内容、图片与内链门槛，因此进入索引清单。既有 152 个较低优先级详情继续保持 `noindex,follow`，本轮不借扩容顺带开放。

发布后 21–30 天重点观察：

1. 新详情已发现、已抓取和已编入索引比例；
2. 12 个家族分别获得的展示、点击与长尾查询；
3. Collection 到详情页的站内点击和复制代码事件；
4. 图片搜索带来的曝光与点击；
5. 出现展示但排名 8–30 的页面，优先补强其正文与相关链接。

在上述信号出现前，不继续以单纯数量为目标开放剩余页面。
