# AimCodes 项目背景

最后更新：2026-08-07

## 一句话定位

AimCodes 是面向全球《无畏契约》玩家的多语种准星发现、实时预览、反应测试推荐与代码复制工具。

## 用户与核心问题

目标用户包括：

- 想直接复制职业选手或热门准星的玩家；
- 想先看真实地图效果再决定的玩家；
- 喜欢某个形状但希望换颜色的玩家；
- 面对大量准星不知道从哪里开始的玩家；
- 英语、西语、巴西葡语和简体中文用户。

核心问题不是“准星数量不够”，而是：

1. 用户不知道哪个准星更适合自己；
2. 代码无法直观展示游戏场景效果；
3. 同类产品多数只服务英语用户；
4. 工具站需要低成本、可持续的自然流量内容。

## 产品价值主张

核心路径：

```text
找到准星 → 在地图中预览 → 调整颜色 → 复制代码
```

辅助路径：

```text
完成三轮反应测试 → 获得反应段位 → 得到一个首选准星 → 直接预览并复制
```

## 当前主要能力

- 62 条可解析准星源数据，外观去重后约 60 种可见样式；
- 职业同款、点状、小型、经典、可爱和趣味等分类；
- 亚海悬城、隐世修所、源工重镇等地图场景预览；
- 颜色预设与最终复制代码同步；
- 三轮反应测试和 9 个游戏语言风格的反应段位；
- 测试结果只推荐一个首选准星；
- 结果分享图、挑战链接和队友成绩对比；
- 英语、西班牙语、巴西葡萄牙语、简体中文；
- 可抓取的本地化 SEO 页面、canonical、hreflang、sitemap；
- GA4 产品漏斗埋点；
- 社媒素材渲染器，支持 MP4、方形图和竖版配套封面。

## 品牌与文案

- 品牌名固定为 `AimCodes`。
- 域名固定为 `aimcodes.com`。
- 视觉基调：深色、竞技、红色高亮、准星元素。
- 文案面向 C 端玩家，简短、直接、略带挑战感。
- 避免后台术语、解释性废话和过度严谨的免责声明式表达。
- 各语言应像当地玩家自然表达，不做逐字直译。

## 增长方向

当前优先级：

1. SEO 收录和长尾准星页面；
2. TikTok、YouTube Shorts、Instagram Reels 的自然内容；
3. 反应测试成绩分享与队友挑战；
4. 通过 GA4 观察准星选择、测试完成、复制和分享漏斗。

在收入能力尚未验证前，不以付费推广为主要增长方式。

## 非目标

- 不开发游戏本体、外挂或自动瞄准功能；
- 不做 Google Drive 或虚拟产品交付平台；
- 不要求用户注册登录或保存账号数据；
- 不在未经验证时接入复杂后端、支付或用户数据库；
- 不为了内容数量批量生产重复、低质量 SEO 页面。
