# AimCodes 社媒自动化月度成本

状态日期：2026-08-16

## 正式运行规格

- 平台：TikTok、Instagram、YouTube；
- 频率：每个平台每天 3 条，共 9 条/天；
- 30 天产量：270 条视频、270 张封面；
- 每条内容调用 1 次文案模型与 1 次视觉检查模型；
- 低于 90 分、视频无音轨、封面规格错误或文案事实不一致时停止发布；
- Instagram 与 TikTok 正文不放裸链接，YouTube 说明只保留一个干净链接。

## 成本监控方法

1. 每条生产报告保存 AI 服务返回的原始 `usage`，不记录 API Key；
2. 每周汇总文案与视觉模型的输入、输出 tokens；
3. Buffer 任一频道待发布数量达到 7 条时暂停新增，先处理失败帖；
4. R2 使用量达到 8 GB 时配置 180 天生命周期；
5. GitHub Artifact 只保留 JSON 报告，禁止重新上传 MP4、封面和抽检帧；
6. AI 月度消费达到 ¥5 时检查重试率、图片 tokens 和模型价格，达到 ¥10 时停止任务并人工复核。

## 不计入的成本

- 人工查看数据、回复评论和运营时间；
- 已有电脑、电力与网络；
- 未来 AdSense、SEO 内容制作或投放预算；
- 因平台政策变化产生的第三方审核或账号服务费。
