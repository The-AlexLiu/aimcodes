# AimCodes 职业选手与分佣基建

## 用户路径

1. 首页职业选手模块进入 `/[locale]/pro-players/`。
2. 选手中心展示已有可靠来源的选手与准星。
3. 用户进入现有准星详情页，在真实地图中预览并复制代码。
4. 后续只有在外设型号可以追溯时，才在选手档案中增加鼠标、键盘、耳机、鼠标垫与显示器。

## 外设发布门槛

每条外设记录至少需要：

- `category`：设备类型；
- `productName`：准确型号，不使用模糊系列名；
- `sourceUrl`：选手、战队、赛事或厂商资料来源；
- `sourceDate`：该来源的发布日期或最后确认日期；
- `checkedAt`：AimCodes 的内部复核日期；
- `affiliateUrl`：可选，必须和资料来源分开；
- `markets`：链接支持的国家或地区；
- `status`：`draft`、`published` 或 `stale`。

缺少来源的记录只能留在草稿数据中，不进入页面、站点地图或结构化数据。

## 分佣链接规范

- 链接旁使用用户能看懂的“分佣链接”标识。
- HTML 使用 `rel="sponsored nofollow noopener"`。
- 优先跳转到访客所在地区可购买的商店；没有合适商店时不展示购买按钮。
- 商品价格、库存和折扣不写死在页面中，除非以后接入可维护的商品 Feed。
- 点击事件统一记录为 `affiliate_click`，至少包含选手、设备类型、商家和页面语言，不记录个人信息。
- 不把分佣链接放在“复制准星代码”等核心操作旁，避免误点并保护玩家体验。

## 推荐推进顺序

1. 先补 10–20 名有可靠准星来源的选手档案。
2. 从鼠标和键盘两个高意图品类开始核实外设。
3. 接入一个覆盖英语市场的联盟平台，跑通点击统计和披露。
4. 根据点击率与国家分布，再补地区商店与更多设备品类。
