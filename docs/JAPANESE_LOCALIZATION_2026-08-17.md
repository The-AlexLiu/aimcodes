# AimCodes 日语本地化

状态日期：2026-08-17

## 为什么优先日语

用户提供的 GSC 数据显示，在没有日语页面的情况下，日本流量的平均排名已经达到 7.3，CTR 为 11.1%。这说明日本用户对准星内容已有明确需求，且现有英语页面已获得一定相关性。新增日语不是盲目扩语种，而是把已经存在的需求承接到更匹配的页面。

## 搜索意图

日语页面围绕真实玩家常用的表达组织，而不是把英语关键词逐字替换：

- `VALORANT クロスヘア`
- `VALORANT クロスヘア おすすめ`
- `VALORANT クロスヘア コード`
- `VALORANT プロ クロスヘア`
- `VALORANT ドット クロスヘア`
- `VALORANT クロスヘア コピー`
- `VALORANT クロスヘア 設定`
- `VALORANT クロスヘア インポート`
- `VALORANT 小さい クロスヘア`
- `VALORANT 面白い クロスヘア`

每个集合、指南和工具页对应独立问题，避免只替换颜色或形状后复用同一段内容。

## 实现范围

- 新增 `/ja/` 语言目录、`ja` hreflang、`ja_JP` Open Graph locale 与自指 canonical；
- 根路径识别设备日语后跳转 `/ja/`；
- 完整日语导航、筛选、预览、复制、反应测试、导入教程和页脚；
- 408 条准星均具备日语名称与玩家口吻说明；
- 25 个日语集合、22 个日语指南、4 个可实际使用的日语工具；
- 首页、目录、准星详情、政策页、404、Breadcrumb、FAQ 和结构化数据本地化；
- 日语 URL 加入网页、准星与图片 Sitemap。

## 构建结果

- 5 种语言；
- 2,335 个本地化 HTML 路由；
- 1,560 个主 Sitemap canonical URL；
- 1,280 个准星详情 Sitemap URL；
- 图片 Sitemap 覆盖 1,405 个页面、2,685 个图片引用。

## 上线后的 GSC 观察

1. 在“效果”报告选择国家/地区为日本；
2. 页面筛选使用包含 `/ja/`；
3. 分别观察日语查询、展示量、平均排名和 CTR；
4. 首轮以抓取和索引为主，不因前 7 天波动批量改标题；
5. 记录原英语页面在日本的基线，确认日语页面是否逐步替代，而不是制造重复页面。

GSC 查询报告展示用户实际输入的原始查询，不会按页面语言自动翻译。全站不加国家和页面筛选时，英语查询占多数不代表多语种路由失效。
